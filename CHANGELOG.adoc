== v2.0.0.2 — 2026-04-23

Integration test suite for the HTML → AsciiDoc pipeline, on top of
the existing per-tag unit specs. A realistic article-shaped HTML
fixture is round-tripped through `ReverseAdoc.convert` and the
AsciiDoc output is asserted on its structural markers (headings,
fenced code, lists, blockquote, thematic break, table) plus
document-level invariants (paragraph separation, heading ordering,
determinism, no leaked `<head>` content, comments dropped).

* 3 new spec files under `spec/integration/`: **sanity** (trailing
  newline, words preserved, no leaked tags), **full_document**
  (fixture `article.html` → AsciiDoc with every expected marker)
  and **structure** (paragraph/heading separation, determinism,
  `<head>` and comments stripped). **11 integration tests,
  46 unit tests, 57 total — all green.**
* New helper `IntegrationHelper` in `spec/integration/spec_helper.cr`
  with `convert` and `fixture` primitives, plus
  `spec/integration/fixtures/article.html` as the round-trip asset.
