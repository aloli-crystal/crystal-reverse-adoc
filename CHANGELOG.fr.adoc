== v2.0.0.3 — 2026-04-23

Correctif de robustesse : `ReverseAdoc.convert("")` (ou une entrée
ne contenant que des espaces) déclenchait `XML::Error: Document is
empty` depuis `XML.parse_html`. Le converter court-circuite
désormais les entrées vides ou purement blanches vers une chaîne
vide, ce qui est le comportement attendu lorsqu'un appelant
transmet un corps de réponse HTTP vide.

* `convert` gagne un garde d'une ligne
  `return "" if html.strip.empty?` en tête.
* 2 nouveaux cas de test unitaires (`convert` avec `""` et avec
  uniquement des espaces) et le test d'intégration précédemment
  neutralisé est réactivé.

== v2.0.0.2 — 2026-04-23

Suite de tests d'intégration pour le pipeline HTML → AsciiDoc, en
complément des specs unitaires par balise. Une fixture HTML réaliste
de style article fait un aller-retour à travers `ReverseAdoc.convert`
et la sortie AsciiDoc est contrôlée sur ses marqueurs structurels
(titres, blocs de code fenced, listes, citations, règles horizontales,
tableaux) ainsi que sur les invariants de document (séparation des
paragraphes, ordre des titres, déterminisme, `<head>` ignoré,
commentaires supprimés).

* 3 nouveaux fichiers de specs sous `spec/integration/` : **sanity**
  (trailing newline, mots préservés, pas de balises résiduelles),
  **full_document** (fixture `article.html` → AsciiDoc avec tous
  les marqueurs attendus) et **structure** (séparation
  paragraphes/titres, déterminisme, `<head>` et commentaires
  ignorés). **11 tests d'intégration, 46 tests unitaires, 57 au
  total — tous verts.**
* Nouveau helper `IntegrationHelper` dans
  `spec/integration/spec_helper.cr` avec les primitives `convert`
  et `fixture`, et une fixture
  `spec/integration/fixtures/article.html`.
